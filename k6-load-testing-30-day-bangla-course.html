Day 06

Checks

Checks functional validation করে।

javascript
import http from 'k6/http';
import { check } from 'k6';

export default function () {
  const response = http.get('https://test.k6.io');

  check(response, {
    'status is 200': (r) => r.status === 200,
  });
}

Multiple:

javascript
check(response, {
  'status 200': (r) => r.status === 200,
  'body exists': (r) => r.body.length > 0,
  'under 500ms': (r) => r.timings.duration < 500,
});

মনে রাখবেন

text
Check fail
≠
Automatically entire test fail

Test pass/fail policy-এর জন্য Threshold ব্যবহার করবেন।

Day 07

Thresholds

এটি k6-এর সবচেয়ে গুরুত্বপূর্ণ concepts-এর একটি।

Threshold হচ্ছে performance-এর pass/fail criteria। Threshold fail হলে test failed status নিয়ে শেষ হতে পারে।

javascript
export const options = {
  thresholds: {
    http_req_failed: ['rate<0.01'],
    http_req_duration: ['p(95)<500'],
  },
};

মানে:

text
Error rate < 1%

95% requests < 500ms

আরও:

javascript
thresholds: {
  checks: ['rate>0.99'],
  http_req_duration: [
    'p(90)<300',
    'p(95)<500',
    'p(99)<1000',
  ],
}

  const payload = JSON.stringify({

Final Thresholds

শুরুতে realistic target হিসেবে practice project-এ ধরতে পারেন:

javascript
export const options = {

  thresholds: {

    http_req_failed: [
      'rate<0.01'
    ],

    http_req_duration: [
      'p(90)<300',
      'p(95)<500',
      'p(99)<1000',
    ],

    checks: [
      'rate>0.99'
    ],

  },

};

এগুলো universal production requirement নয়। আপনার actual SLO/SLA অনুযায়ী thresholds নির্ধারণ করবেন। k6 thresholds মূলত SLO-type pass/fail criteria codify করার জন্যই ব্যবহার করা হয়।

Bonus — k6 Browser Testing

API/protocol testing শেষ করার পরে browser-level performance testing শিখবেন।

বর্তমান k6-এর k6/browser module Chromium browser চালিয়ে page interaction এবং frontend performance test করতে পারে।

Basic:

javascript
import { browser } from 'k6/browser';

export const options = {
  scenarios: {
    browser_test: {
      executor: 'shared-iterations',

      options: {
        browser: {
          type: 'chromium',
        },
      },
    },
  },
};

export default async function () {

  const page = await browser.newPage();

  try {

    await page.goto(
      'https://test.k6.io/'
    );

  } finally {

    await page.close();

  }

}

Browser testingটা Day 30-এর পরে advanced module হিসেবে নিন।
